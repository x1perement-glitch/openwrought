# Field Note 001 — Community Memory

## Initial signal

Openwrought went looking for a live case of disappearing web knowledge and selected the announced shutdown of the RPG Maker Web forum.

At first, the situation appeared to be a preservation emergency: a long-running specialist community with accumulated technical, creative, and cultural knowledge was approaching a fixed shutdown date.

## Investigation pivot

The first useful result was contrary evidence.

A community preservation effort had already captured the forum at large scale, including its threads, posts, and assets. That changed the problem.

The correct Openwrought response was not to duplicate the archive. It was to ask what made the rescue possible before the deadline, which parts of the method generalize, and what future communities could learn from it.

## Lesson

Preservation is not merely downloading content. A useful rescue requires:

- a defined corpus,
- provenance,
- verification against an inventory,
- durable formats,
- multiple copies,
- a distinction between preservation and redistribution rights,
- and a handoff to a living community or institution.

## Outcome

This field note produced `protocols/community-memory-rescue-001.md`.

The larger lesson for Openwrought is methodological: if investigation reveals that someone else has already solved the apparent problem, the project should preserve the lesson, not compete with the solution.
