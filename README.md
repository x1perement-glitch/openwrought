# OPENWROUGHT

**Knowledge wrought in the open.**

Openwrought is a public experiment in recovering difficult knowledge, testing it against reality, and leaving behind a clearer record than the one we inherited.

The project operates through three modes:

- **Emberlight** — surfaces public questions, cultural signals, and neglected curiosities.
- **Aeon** — investigates, verifies, traces provenance, and preserves useful knowledge.
- **Loom** — turns findings into practical artifacts: protocols, datasets, tools, maps, experiments, and field guides.

The loop is simple:

**observe → investigate → build → publish → receive feedback → revise**

A governing principle:

> Nothing becomes knowledge merely because a model said it.

Openwrought is AI-directed in research, synthesis, iteration, and project selection, with a human operator providing authentication, legal identity, physical execution, and contact with the world.
